Nanitics is an open-source project distributed under the Apache License
2.0 (see [LICENSE](LICENSE)). The code is freely copyable, modifiable,
and redistributable under those terms. The **name** and **mark**
"Nanitics", however, are a separate legal asset: they are a trademark
owned by Living The Dream Holding B.V. and used by Solid Software B.V.
under an exclusive licence. This document describes how the name and
mark may be used.

## Ownership

The `Nanitics` name and mark are owned by **Living The Dream Holding
B.V.** (Dutch holding company, registered in the Netherlands).
**Solid Software B.V.** (Dutch operating company) is the authorised
maintainer of the Nanitics project under an exclusive trademark
sub-licence from Living The Dream Holding B.V.

## The Nanitics mark — permitted uses

The following uses are explicitly permitted and do not require further
permission:

- **"Compatible with Nanitics"** — for third-party libraries or tools
  that interoperate with the SDK.
- **"Built with Nanitics"** — for applications that use the SDK.
- **"For Nanitics"** — for adapters, plugins, or extensions targeting
  the SDK.
- **"Works with Nanitics"** — for ecosystem integrations.
- Accurate descriptive use of the name in articles, documentation,
  comparison tables, academic papers, technical writing, conference
  talks, tutorials, and similar.
- **Forking the code under Apache-2.0 is explicitly permitted**,
  including modifications. Forks may not be distributed under the name
  "Nanitics" or use the Nanitics mark in a way that implies endorsement
  by, or origin from, Solid Software B.V. (see the next section).

## The Nanitics mark — prohibited uses

The following uses are not permitted without prior written permission
from Solid Software B.V.:

- Distributing a fork, derivative, or modified version under the name
  "Nanitics" or any name that creates confusion as to origin — including,
  without limitation, names such as "Nanitics-Plus", "Nanitics-Pro",
  "Nanitics Cloud" (by anyone other than the Maintainer), and similar
  constructions.
- Using the Nanitics name or mark as the primary identifier of a
  competing product or service.
- Squatting on `nanitics-*` domain names, package names on any public
  registry, or social handles with intent to pass off as the project or
  divert users.
- Using the Nanitics name to imply endorsement of, or sponsorship by,
  Solid Software B.V. or Living The Dream Holding B.V.
- Reusing the Nanitics logo (no logo exists today — logo design is
  deferred post-launch; this policy is forward-compatible).

## Fair use and nominative use

Nominative fair use of the `Nanitics` name is not restricted by this
policy. You may refer to Nanitics in articles, blog posts, comparison
tables, academic papers, documentation, conference talks, and other
contexts where using the name is necessary or descriptive, without
seeking permission in advance. This policy does not extend to any use
that implies endorsement by, sponsorship by, or origin from the
Maintainer.

## Logo policy

No Nanitics logo is published today. Logo design is deferred
post-launch. Once a logo is published, reuse of the logo will require
written permission under terms that will be added here at that time.
This section is intentionally forward-compatible.

## ™ and ® notice

The Nanitics mark is used with the **™** notice pending registration.
Trademark applications are on file with the EUIPO (European Union) and
the USPTO (United States). Once each registration grants, the **®**
notice will be adopted for the respective jurisdiction.

## Contact for brand inquiries

For brand-licensing questions, written permission requests, enforcement
matters, or any question this policy does not answer, contact
[`trademark@nanitics.dev`](mailto:trademark@nanitics.dev).

## How this policy evolves

This policy sits alongside [GOVERNANCE.md](GOVERNANCE.md) and
[LICENSE](LICENSE) as part of the open-core legal scaffolding for the
Nanitics project. Changes to this policy flow through PR review like any
other change to this repository. Material changes (new prohibited uses,
changes to who owns or is authorised to use the mark) will be announced
in the *Announcements* category of GitHub Discussions alongside the PR.
